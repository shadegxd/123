# 🎓 University Data Science Projects

This repository contains a collection of small data science projects completed throughout my studies at Central European University (B.Sc. in Data Science and Society). These projects were developed as part of coursework, hackathons, and independent learning exercises.

They reflect my exploration of data analysis, machine learning, statistical modeling, and portfolio optimization — and serve as a snapshot of my technical growth during university.

---

## 📁 Contents

| Project | Description |
|--------|-------------|
| `tournament_predictor.py` | A machine learning model predicting outcomes of esports tournaments using historical match and player data (1998–2023). Uses regression and random forest classifiers. |
| `inequality_behavior_analysis.py` | An analysis of how income inequality correlates with alcohol and smoking behaviors across US states. Focuses on socioeconomic vs. cultural factors. |
| `portfolio_optimization.py` | A linear programming approach to building optimal mutual fund portfolios under risk-return tradeoffs and sector constraints. |

> 📌 *Some projects were developed under tight deadlines (e.g. hackathons) and are here for reference or improvement later.*
